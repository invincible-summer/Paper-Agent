# 使用文档

欢迎使用 **Paper Agent**。这是一个面向文献检索、论文阅读和研究分析的智能体：你用一句话描述研究需求，它即可完成检索、深读、分析、综述写作与成果导出。

整个产品以**对话为唯一入口**——没有复杂的按钮和菜单，会用自然语言提需求，就会用这个产品。新会话的输入框上方预置了几条建议话术，可以直接点击开始。

## 💡 写在前面：常见问题速查

> 由于清小搭侧 API 接入文档约束了 **2 分钟的单轮对话处理时限**，而许多国外论文平台在国内的正常访问较慢、部分内置工具需要被多次调用来处理您的复杂请求，因此有可能出现超时提醒。这时可以**新开一轮对话**继续完成之前没有结束的任务，Agent 可以正常读取您的上下文（尤其是对于您上传的需要解读的论文文件，**Paper Agent** 会先做一次 **RAG** 处理，需要一定时间，第一轮对话大概率处理超时，等待下一轮才能正常使用论文文件）——虽然这一定程度影响体验感，但这是为了保证回答质量和准确性无法避免的喵 QwQ

## 快速上手

典型的三步流程：

1. **描述主题**：说明你的研究主题、问题或关键词，越具体越好。
2. **检索文献**：需要文献时，明确告诉智能体进行论文检索。
3. **深入分析**：指定某篇或某几篇论文后，继续要求问答、比较、综述或生成研究地图。

一条完整的示例指令：

> 帮我检索「基于图结构学习的图神经网络节点分类方法」近五年的代表论文，然后对核心的三篇做结构化深读，最后生成一份文献综述。

一次典型的完整工作流（可以全部在同一个会话里完成）：

1. 说清主题 → **论文检索**，得到核心集与候选集；
2. 挑几篇追问 → **论文问答**（网络论文）或上传原文后**深度阅读**（全文级）；
3. 「生成研究地图」→ 交互式**论文谱系图** + 主题聚类 + 时间脉络；
4. 「检查这批论文的引用可靠性」→ 排查撤稿、勘误与未正式发表的预印本；
5. 「围绕这些论文写一份文献综述」→ 在线预览 + Markdown / Word 双格式下载；
6. 「导出这批论文的 BibTeX」→ 引用文件一键下载。

## 文献检索

文献检索是所有功能的起点：研究地图、文献综述、引用导出都基于会话内已检索到的论文工作。

### 怎么发起一次检索

直接用一句话说明主题即可，例如：

| 你想做的 | 示例话术 |
|---|---|
| 检索一个方向 | 帮我检索「扩散模型在图像生成中的应用」近三年的代表论文 |
| 带上你的研究构想 | 我的研究构想是「用知识图谱增强推荐系统的冷启动表现」，帮我检索相关论文 |
| 限定语言 | 只检索中文文献 / 只检索英文文献 / 中英文文献都要 |
| 换个角度再找一批 | 换个思路，从「对比学习」的角度再检索一批相关论文 |

一次检索里值得告诉它的三件事：

- **主题**（必说）：越具体越好，见下文「检索技巧」；
- **研究构想**（可选）：你自己的研究想法或课题背景，它会据此判断文献相关性；
- **语言偏好**（可选）：中文 / 英文 / 中英文，不说明时默认中英文都检索。

### 检索范围：9 个免费学术平台

检索覆盖 **OpenAlex、Semantic Scholar、arXiv、Crossref、Europe PMC、DOAJ、HAL、OpenAIRE、CORE** 共 9 个开放学术平台，全部通过各平台官方提供的合法合规接口访问。发起检索后，智能体会先理解意图、把主题拆解成若干子方向，再到多个平台并行检索，最后统一重排挑选，因此**不需要**（也不建议）你逐个平台分开检索。

### 结果怎么读：核心集与候选集

检索结果按相关性分成两层，篇数不固定、随主题质量自适应：

- **核心集**：与主题最相关的一批论文，逐篇编号展示。每篇显示标题、年份、被引次数、相关程度，以及指向原文页面的链接（优先使用 DOI）。核心集还会按拆解出的**子方向**打上分组徽章，方便你按线索浏览。
- **候选集**：相关性稍弱但可能值得一看的论文，默认折叠，需要时可以让它展开，或直接点名「看看候选集第 5 篇」。

检索完成后，结果里会明确告诉你：**多少篇有有效摘要、多少篇缺摘要**。

### 什么是「有效摘要」

平台对网络检索到的论文**只保留元数据和当前有效的非空摘要**，不探测、不下载全文：

- 有有效摘要的论文，可以参与后续的问答、比较、综述、研究地图等所有分析；
- 缺摘要的论文只能作为条目参考，**不会**进入摘要问答和文献综述——综述引用它时请自行补充材料。

想对某篇论文做全文级分析：请自行获取原文后**上传文件**（见「文件上传说明」）。

### 检索技巧与常见问题

1. **主题具体化**。不建议直接查找「图神经网络相关的论文」，而应具体化为「查找基于图结构学习的图神经网络节点分类方法相关的研究」。范围太大时结果会发散，核心集质量下降。
2. **不要重复检索**。会话里已经检到的论文，后续直接点名即可（如「上面第 3 篇」「标题里带 contrastive 的那篇」），再次发起检索反而会浪费时间和轮次。
3. **超时不是失败**。多平台检索耗时较长，若单轮超时，部分成功的结果仍会整理成表格返回；可以新开一轮对话说「继续完成刚才的检索」。
4. **提示「无可用论文平台」**：说明当前部署没有开启任何检索源，请联系管理员在管理页面配置。

## 论文问答

针对**当前会话里**的论文和上传文件直接提问，是最常用的功能：

- 「这批论文里哪些用了对比学习？给出出处」
- 「第 2 篇和第 5 篇的核心贡献分别是什么？」
- 「这篇论文有哪些章节？先给我一个目录」

几点说明：

- 答案会附**引用来源**（篇名 + 对应章节），且只基于会话内可用的证据作答：网络论文为摘要级证据，上传文件为全文级证据；
- 「有哪些部分 / 章节目录」这类结构性问题可以直接问，会返回完整的章节大纲；
- 手上有明确 DOI 时，可以直接把 DOI 给它点名分析，不必先检索；
- 会话内保留上下文，直接说「上面第 3 篇」即可继续追问。

## 论文深读

**深度阅读只针对你上传的文件**（PDF / DOCX 等全文）；网络论文只做摘要级分析，点名要求深读网络论文会被明确拒绝并提示你上传原文——这是数据合规设计，平台不从网络拉取全文。

上传文件后说：

> 深读我刚上传的这篇论文，重点看方法和实验部分。

深读结果是一张结构化卡片，包含：

- **12 个固定字段的逐篇摘要**：研究问题、方法、理论框架、主要发现、主要贡献、局限、数据集、基线方法、样本规模、干预措施、结果、未来工作；
- **完整章节目录**：每个章节标注所在页码，方便回到原文定位；
- **文档信息**：页数、字符数、是否扫描件（OCR 恢复）、完成视觉理解的图表数量；
- **图表元素入口**：卡片下方列出检测到的图、表、公式标签，**点击任意标签**，输入框会自动填好「请详细解读 figure-3」之类的追问话术，回车即可看单个元素的详细解读（见「图表与公式解读」）。

扫描版 PDF、含内嵌图片的 DOCX、独立图片也会尽力做 OCR 与版面恢复后再深读。

## 研究地图与论文谱系

研究地图帮你从「一堆论文」变成「一张领域全景图」。**前提是会话里已经有过一次检索**（或导入了文献库），然后说：

> 生成研究地图。 / 画一下这批论文的谱系图。

### 一次地图输出四样东西

1. **领域脉络**：一段文字综述，讲清这个主题下的研究是如何演化组织起来的；
2. **交互式论文谱系图**：核心输出，详见下节；
3. **主题簇卡片**：论文自动聚成若干主题簇，每簇给出簇标签、论文篇数、一段概述和论文清单，可折叠展开；
4. **时间脉络**：按年份排列的代表工作时间线，快速看清「哪个年代发生了什么」。

### 谱系图操作指南

谱系图中每个节点是一篇论文，节点之间的连线表示关系。支持的操作：

- **悬停节点**：弹出气泡，显示标题、年份、被引次数、所属主题簇；
- **点击节点**：打开详情面板——论文元信息、摘要片段、**引用关系双向列表**（它引用了谁 / 谁引用了它，点击可跳转到对应节点）、「打开原文」外链，以及**「深问这篇」**按钮（自动填好提问话术，直接回车就能针对这篇继续追问）；
- **点击连线**：说明这条边代表什么——是**真实引用关系**（含方向）还是**语义相似**（研究内容相近但没有引用）；
- **聚焦模式**：点击节点进入后，会高亮它的引用子树，祖先链按年份渐变加粗，顺着看就是一条「学术家谱」；
- **顶部筛选**：按主题簇筛选（簇标签 chips）、候选集开关（默认只画核心集，打开后把候选集也画进去）、语义边开关（只想看真实引用关系时关闭它）；
- **缩放与拖拽**：右下角 +/− 按钮缩放，空白处拖拽平移；论文密集区域会出现「+N」聚合节点，点击展开细看。

### 阅读路径

不知道从哪篇读起时，直接问：

> 我该按什么顺序读这批论文？

会得到一个带顺序的阅读列表，每篇标注角色徽章——**奠基**（必读的开创性工作）、**桥梁**（承上启下的关键工作）、**前沿**（最新进展）——并附每篇的推荐理由。

### 导出地图

对地图说「导出研究地图」，得到两个文件：**美化版 SVG 谱系图**（可直接插进 PPT 或论文）和 **Markdown 报告**（领域脉络、主题簇、时间脉络的完整文字版）。

## 文献综述

围绕会话内的文献生成一篇结构完整的中文综述，是检索与研究地图之后最常见的产出。

### 综述的证据从哪来

综述只使用**当前会话**里的材料，且严格区分证据层级：

- 网络检索的论文：只有**有效摘要**（缺摘要的论文自动排除，不会硬编内容）；
- 你上传的文件：**完整全文**，可以做深入的方法比较；
- 其他会话检索到的论文不会自动带入——需要的话请在新会话里重新检索或重新上传。

### 综述的固定结构

每篇综述都按固定骨架组织，共八个部分：**引言 → 综述范围与证据基础 → 分类框架 → 方法比较 → 争议与空白 → 未来方向 → 结论 → 纳入文献与证据层级**。最后一节会逐篇列出纳入的文献及其证据层级（摘要级 / 全文级），引用时心里有数。

### 篇幅可控

可以直接指定目标长度：

> 围绕这批论文写一份 8000 字左右的文献综述，重点比较方法差异。

字数上限约 2 万字；如果要求得过短，系统会自动放宽篇幅以保证结构完整。

### 拿到什么

- 对话内的**滚动预览**，可以先读再改；
- 综述生成成功时会**同时产出 Markdown（.md）和 Word（.docx）两个文件**，在结果卡片上一键下载，无需额外操作。

### 推荐流程

1. 检索（可配合 `.bib` 文献库导入，见下文）；
2. 「检查这批论文的引用可靠性」——先排查撤稿、勘误关切和尚未正式发表的预印本；
3. 「围绕这些论文写一份文献综述」，可附带重点要求（如侧重方法比较、争议梳理）；
4. 对预览结果提修改意见继续打磨，或下载后自行加工。

## 学术写作辅助

除综述外，还有一组写作与研究技能，直接用自然语言提出需求即可，智能体会自动判断并加载：

| 场景 | 直接说 |
|---|---|
| 多篇横向比较 | 把核心集的三篇按任务、方法、数据集做横向对比（没提到的维度会如实标「未报告」） |
| 研究空白识别 | 基于这批论文归纳研究空白，并评估我的选题是否有撞车风险 |
| 审稿式批判阅读 | 以审稿人视角评审第 2 篇论文（附可复现性检查清单） |
| 组会汇报准备 | 帮我准备这篇论文的组会汇报大纲，讲 15 分钟，附可能被问到的问题 |
| 草稿评审 | （上传草稿后）评审我的草稿，指出结构和论证问题（会先自动做结构与格式体检再评内容） |
| 相关工作章节 | 帮我写论文的相关工作章节（按流派组织；要整篇综述请用「文献综述」功能） |
| 写作教练 | 帮我搭论文框架 / 起草初稿 / 批改这一段 / 润色摘要（初稿中的数据一律用占位符，不允许编造） |
| 选题指导 | 我还没定题，结合文献帮我找 2–3 个可行的研究方向 |
| 论文结构骨架 | 我的硕士论文章节骨架和篇幅比例怎么安排 |
| 格式要求对照 | 按我们学校的格式要求逐条核对我的草稿 |
| 逐句证据核对 | 检查我写的这段话每一句有没有文献支撑 |

另有一组**纯规则体检**（不依赖模型、结果客观、秒出）：

- **结构体检**（需上传草稿）：「复查我的章节结构」——章节树完整性、IMRaD 缺失项、篇幅比例失衡、摘要长度、引用卫生、图表统计；
- **格式检查**：「检查格式是否合规」——图表编号连续性、引用风格混用、GB/T 7714 国标规范度、关键词数量、标题断号；LaTeX 源码会检查 `\cite` / `\ref` 配对；可以提供具体格式要求逐条对照；
- **引用可靠性**：「检查这批论文有没有撤稿或勘误」——逐篇查询撤稿记录、勘误关切、预印本是否已正式发表（写综述或投稿前建议先跑一遍）。

## 图表与公式解读

针对**上传文件**中的图表和公式提供两级解读：

- **图表导览**：「列出这篇论文的图表」——按文件列出全部图、表的编号、类型、页码和题注，点击任意条目自动填好追问话术；
- **单个元素详解**：点击深读卡片里的图表标签，或直接说「详细解读 Figure 3」——展示原图裁剪、内容描述、成分 / 关系 / 比较维度分析；**表格**会渲染成规整的 Markdown 表格；**公式**给出 LaTeX 源码与变量释义。

视觉理解服务不可用时会自动降级为题注和文本分析，功能不中断（结果中会如实说明）。

## 文献库导入与领域计量

- **导入个人文献库**：上传 Zotero / EndNote / Mendeley 导出的 `.bib` 文件后说「导入我的文献库」——自动解析、通过 DOI 校验补全元数据、去重后并入**候选集**（不影响核心集的排序），需要时点名即可参与后续分析；
- **领域计量普查**：「这个领域近十五年的发文趋势如何？哪些机构和作者最高产？」——年度发文趋势图、高产作者 / 机构 / 期刊榜单和一句话领域画像。注意它看的是**整个领域**的宏观统计，而研究地图看的是**你手上这批论文**的内部结构。

| 稿件 | 把下面这段定稿导出为 docx | 把**最终定稿文本**粘贴在指令里，导出 `docx`（默认）、`tex`（中文可编译）或 `md` |

## 文件上传说明

- **支持格式**：PDF、DOCX、TEX、TXT、MD、BIB、PNG、JPG、JPEG、WebP；
- **大小限制**：单个文件不超过 20 MiB；
- 旧版 `.doc` 不受支持，请先另存为 `.docx` 再上传；
- 上传方式：输入框的回形针按钮，或直接把文件拖进对话窗口；图片附件可以点击预览；
- 上传后即可在对话中分析；版面解析、OCR 与图片视觉理解按需进行，无需等待预处理。

## 账户与数据

- 首次使用需登录；是否开放注册、是否需要邮箱验证码由管理员设置，管理员开启游客访问时未登录也可试用；
- 对话历史、上传文件与导出成果均**按账号隔离**，其他用户不可访问；
- 会话内保留上下文（超长自动压缩），可直接说「上面第 3 篇」继续追问；
- **跨会话不保留长期记忆**，新会话请重新提供背景和文献；
- 左侧栏可以新建对话、重命名和删除历史会话。

## 清小搭 / OpenAI 兼容接口接入

平台同时提供 **OpenAI 兼容接口**，可接入清小搭或任何支持自定义 OpenAI 接口的客户端：

- **获取密钥**：管理员在网页端「管理 → Agent API 密钥」页创建，密钥以 `pa_live_` 开头，**仅在创建时完整显示一次**，可随时撤销；
- **接入方式**：接口地址填 `https://<平台域名>/v1`，密钥填 Agent API 密钥，模型名填 `paper-agent`；支持流式输出；
- **体验差异**：网页端的交互卡片在接口侧表现为——工具完成时正文里的一行状态卡、检索完成后的完整论文结果表（Markdown 表格）、研究地图 / 综述 / 稿件等以文件附件形式下发、技能加载在思考栏中提示；
- **时限**：接口侧单轮默认约 95–105 秒（清小搭网关整体 2 分钟），超时建议新开一轮继续；同一会话内流式中断后可以恢复论文集等上下文状态。

## 注意事项
