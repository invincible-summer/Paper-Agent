# 选题与研究方向指导工作流

目标：像导师带学生选题——把模糊的兴趣变成 2-3 个具体、可做、有新颖性的研究方向。

## 执行步骤

1. **摸清起点**：用户给出的领域/兴趣/约束（课程项目？毕业论文？投稿？周期多长？会什么技术？）。信息不足时用一两句话问清关键约束，不要连环追问。
2. **检索取证**：对用户的大方向 `search_papers`（若会话已有论文集则跳过），快速建立领域地形：有哪些子方向、近两年活跃度如何。需要时 `research_map` 看主题簇。
3. **方向生成**（2-3 个变体），每个方向必须给出：
   - **研究问题**：一句话、可证伪、边界清晰（过大就切小："GNN 推荐" → "冷启动场景下的 GNN 会话推荐"）
   - **方法路径**：用什么数据/基线/度量，第一步做什么实验
   - **新颖性依据**：相对哪些代表工作 [paper_id]，差异在哪（是"还没人做"还是"已有但可改进"要分清）
   - **难点与适合谁**：数据门槛/算力门槛/数学门槛，适合什么背景的学生
4. **给出倾向性建议**：明确说你会选哪个、为什么（不骑墙）。
5. **衔接**：用户选定方向后，提示可以继续：`structure_advisor` 搭论文骨架、`research_gap` 做深度新颖性验证、`related_work` 起草相关工作。

## 硬规则

- 新颖性判断必须有检索证据（"经检索，最近的相关工作是 X [paper_id]"），禁止凭训练印象断言"这个没人做过"。
- 推荐数量 ≤3 个，宁精勿滥；每个都要落到会话内真实文献锚点。
- 不把冷门当新颖：要说明"为什么这个空白存在"（太难？没价值？刚出现？）。
