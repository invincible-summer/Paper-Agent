# 段落证据锚定工作流（逐句证据核对）

目标：像严谨的审稿人一样，检查用户贴出的一段草稿里每一个"可证伪主张"是否有文献支撑，并指出该在何处插入引用、有没有相悖证据。输出一张可操作的对照表。

## 执行步骤

1. **取材与确认**：用户贴出的段落即评审对象。证据库是会话内已检索/已深读的论文集（核心集 + 候选集）。若会话里还没有论文，先问用户研究领域并 `search_papers` 检索一批——证据核对的质量直接依赖它。
2. **拆主张（1 次 utility LLM）**：把段落拆成 ≤8 条**可证伪主张**（falsifiable claims）——可被证据支持或反驳的论断（如"方法 X 优于 Y""指标提升了 15%""该问题尚未被研究"）。跳过纯定义、过渡句、主观评价这类无法证伪的句子。超过 8 条时取最关键的 8 条，并在收尾说明已截断。
3. **逐条取证（每条 1 次 ask_papers，总计 ≤8 次）**：对每条主张调 `ask_papers(query="<把主张改写成检索式>", top_k=5)`，从会话文献取证。判定每条主张的结论：
   - **直接支持**：有文献明确给出相同结论/数据。
   - **间接支持**：有文献支撑前提或相邻结论，需推断。
   - **无证据**：会话文献里找不到支持（不要硬凑）。
   - **有相悖证据**：有文献给出不同或相反结论（这是最高优先级风险，必须标出）。
4. **汇总对照（1 次 LLM）**：生成"原文句 → 主张 → 证据与强度 → 建议插入引用位置"对照表。强度分档：强（直接支持）/ 中（间接支持）/ 弱或无 / 相悖。
5. **输出**（用户语言，markdown）：
   - 总体判断（1-2 句：这段论证的证据总体是否扎实，最大风险是什么）
   - 逐句对照表（原文句 · 主张 · 结论 · 证据来源 [paper_id] · 建议插入位置）
   - 无证据主张清单（单独列出，标注"需自补实验/数据 或 另行外引"，不硬凑会话文献）
   - 相悖证据提醒（若有，置顶强调）

## 硬规则

- 推荐引用只能来自会话论文集，全部带 [paper_id]；找不到就如实说"无证据"，绝不编造文献或张冠李戴。
- 一次只评一段（或用户指定的几段）；整篇评审请走 draft_review。
- 取证总次数 ≤8 次 ask_papers + 1 次拆主张 + 1 次汇总，不要超额补查。
